# 💰 Expense Tracker Pro

A Python-based command-line application for managing personal expenses, tracking spending, and saving financial records.

This project is being developed step by step, with the goal of evolving into a web-based personal finance dashboard.

## ✨ Features

- Add expenses with a category, amount, and description
- View all recorded expenses
- Calculate total spending
- Calculate spending by category
- Find the most expensive expense
- Delete existing expenses
- Save and load expenses using JSON
- Validate user input and handle common errors
- Automated unit tests

## 🛠️ Technologies

- Python 3
- JSON for local data storage
- Python `unittest` for automated testing
- Git and GitHub for version control

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/AhmadBiko/expense-tracker-pro.git
cd expense-tracker-pro
```

Run the application:

```bash
python main.py
```

No third-party Python packages are required for the current CLI version.

## 🧪 Testing

Run the automated tests:

```bash
python test_expense_tracker.py
```
